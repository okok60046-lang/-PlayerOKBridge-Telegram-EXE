# Исправления PlayerokBridge

Внесены изменения вне модулей интеграции PlayerOK.

## Изменено

1. `Views/MainWindow.Snap.cs`
   - Snap больше не принуждает окно к `MinWidth`/`MinHeight`, если половина рабочей области монитора меньше минимального размера.
   - Минимальные размеры временно уменьшаются на время Snap и восстанавливаются при откреплении или максимизации.
   - Это устраняет геометрический конфликт на небольших мониторах.

2. `Services/AppHost.cs`
   - Catch-up пропущенных покупок расширен с 2 до 50 страниц, чтобы уменьшить риск пропуска сделок при всплеске продаж.
   - Остановка Python-процесса стала асинхронной, ожидание ограничено 5 секундами.
   - Фоновые задачи монитора чатов и зависших сделок теперь отслеживаются; `CancellationTokenSource` освобождается после завершения соответствующей задачи, а не по произвольному таймеру.

3. `Core/ListingStatsStore.cs`
   - История удалённых объявлений очищается после 90 дней отсутствия в текущем списке.
   - Добавлен предел в 10 000 ключей истории, чтобы локальное хранилище не росло бесконечно.
   - Активные объявления не удаляются только из-за давности последней точки.

4. `PlayerokBridge.csproj`
   - `requirements-bot.txt` включён в копирование при сборке и публикации, чтобы инструкция установки Python-зависимостей работала из опубликованного комплекта.

## Намеренно не изменялось

Полностью оставлены без изменений:
- `Playerok/` — C#-клиент и GraphQL/API-транспорт;
- `playerokapi/` — Python-библиотека и WebSocket listener.

Поэтому замечания аудита, относящиеся к этим каталогам, не исправлялись согласно запросу.

## Проверки

- Python: 11 файлов, синтаксических ошибок нет.
- JSON: 5 файлов, ошибок разбора нет.
- `PlayerokBridge.csproj`: XML корректен.
- Изменено 4 исходных файла.
- Файлы в `Playerok/` и `playerokapi/` не изменялись.
- Сборка .NET не выполнена: в среде отсутствует .NET SDK (`dotnet`).

Перед эксплуатацией рекомендуется выполнить `dotnet publish -c Release` на Windows с установленным .NET 8 SDK и проверить Snap на мониторах с разными разрешениями и DPI.
