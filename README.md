# -PlayerOKBridge-Telegram-EXE
PlayerokBridge — программа для автоматизации продаж на PlayerOK. Автоответы покупателям, AFK-режим, управление чатами, Telegram-уведомления, статистика сделок и удобный графический интерфейс.

Не уверен, можно ли оставлять комментарии под репозиториями, но если проект наберёт достаточно реакций, выпущу APK-версию приложения.
