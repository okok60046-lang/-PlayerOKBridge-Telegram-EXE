PlayerOK Bridge

PlayerOK Bridge — приложение для работы с PlayerOK. Позволяет отслеживать покупки, читать и отправлять сообщения, настраивать автоответы и получать уведомления.

Приложение имеет графический интерфейс на C# и Avalonia. Для Telegram-бота используется Python.

ВОЗМОЖНОСТИ

- Просмотр чатов и переписка с покупателями.
- Автоматическое обновление сообщений.
- Автоответы после покупки товара.
- Отдельные шаблоны ответов для разных товаров.
- AFK-режим с дополнительным сообщением.
- Отправка фотографий в чате.
- Уведомления о новых покупках.
- Просмотр товаров и информации о продажах.
- Статистика продаж.
- Уведомления о невыданных заказах.
- Управление через Telegram-бота.
- Настройка внешнего вида приложения.
- Работа в системном трее.
- Журнал событий и ошибок.

ТРЕБОВАНИЯ

Для запуска и сборки понадобятся:

- Windows 10 или Windows 11.
- .NET 8 SDK.
- Python 3.
- Токен PlayerOK.
- Токен Telegram-бота.

УСТАНОВКА

1. Скачайте проект.

Склонируйте репозиторий:

git clone https://github.com/ВАШ_АККАУНТ/PlayerokBridge.git

Либо скачайте архив проекта через Code → Download ZIP.

2. Установите зависимости.

Откройте терминал в папке проекта и выполните:

python -m pip install -r requirements-bot.txt

Если команда python не работает, используйте:

py -m pip install -r requirements-bot.txt

3. Соберите приложение.

Выполните:

dotnet restore

dotnet build -c Release

Для создания отдельной сборки под Windows x64:

dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true

Готовые файлы появятся в папке:

bin/Release/net8.0/win-x64/publish/

Файл bot.py и остальные необходимые файлы должны находиться рядом с опубликованным приложением.

ПЕРВЫЙ ЗАПУСК

1. Запустите PlayerOK Bridge.
2. Откройте раздел «Настройки».
3. Введите токен PlayerOK.
4. Укажите токен Telegram-бота.
5. Введите свой Telegram ID.
6. Нажмите «Сохранить».
7. Перейдите в раздел «Работа» и нажмите «Запустить».
8. Откройте Telegram и отправьте боту команду /start.

После этого приложение подключится к PlayerOK.

НАСТРОЙКА АВТООТВЕТОВ

1. Откройте раздел «Ответы по товарам».
2. Создайте новый шаблон.
3. Укажите ключевые слова для определения товара.
4. Напишите сообщение, которое будет отправляться покупателю.
5. Сохраните шаблон.

В сообщениях можно использовать переменные:

{buyer} — ник покупателя.

{seller} — ник продавца.

{item} — название товара.

{price} — цена товара.

{deal_id} — номер сделки.

Пример сообщения:

Здравствуйте, {buyer}!

Спасибо за покупку товара {item}.

Если возникнут вопросы, напишите мне.

AFK-РЕЖИМ

AFK-режим отправляет дополнительное сообщение после основного автоответа.

В настройках можно указать текст сообщения и задержку перед отправкой.

Порядок отправки:

1. Покупатель получает основной автоответ.
2. Приложение ждёт установленное время.
3. Покупатель получает AFK-сообщение.

Сообщения отправляются один раз на сделку.

TELEGRAM-БОТ

В боте доступны следующие команды:

/start — запуск бота.

/balance — просмотр баланса.

/stats — статистика.

/deals — список сделок.

/check <название лота> — проверка товара.

Также можно ответить на уведомление в Telegram, чтобы отправить сообщение покупателю.

ГДЕ ХРАНЯТСЯ НАСТРОЙКИ

Пользовательские данные сохраняются в папке:

%AppData%\PlayerokBridge\

Здесь находятся настройки приложения, шаблоны ответов и другие рабочие данные.

При переносе на другой компьютер можно скопировать нужные файлы из этой папки.

Не загружайте в GitHub токены, cookies, данные авторизации и личную переписку.
